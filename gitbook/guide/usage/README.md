# 使用方法

このセクションでは、BSVネットワーク（JpyNetworkとLariNetwork）の使用方法について説明します。ワンクリックセットアップソリューションを使用すると、簡単にネットワークを起動、管理、停止することができます。

## 内容

- [ネットワークの起動](starting-networks.md) - JpyNetworkとLariNetworkの起動方法
- [ステータスの確認](checking-status.md) - ネットワークの状態を確認する方法
- [ネットワークの停止](stopping-networks.md) - ネットワークを安全に停止する方法
- [デスクトップショートカット](desktop-shortcuts.md) - 便利なデスクトップショートカットの作成と使用方法

## 基本的なワークフロー

BSVネットワークを使用する基本的なワークフローは以下の通りです：

1. **セットアップ**: 初回のみ、`setup.sh`スクリプトを実行してネットワークを設定します。
   ```bash
   ./setup.sh
   ```

2. **起動**: `start.sh`スクリプトを実行して両方のネットワークとトークンブリッジを起動します。
   ```bash
   ./start.sh
   ```

3. **ステータス確認**: `status.sh`スクリプトを実行してネットワークの状態を確認します。
   ```bash
   ./status.sh
   ```

4. **操作**: トークンブリッジAPIを使用してネットワーク間でトークンを交換します。

5. **停止**: 作業が終了したら、`stop.sh`スクリプトを実行してネットワークを停止します。
   ```bash
   ./stop.sh
   ```

## スクリプトの概要

| スクリプト | 説明 |
|------------|------|
| `setup.sh` | 初期セットアップを行います。必要なディレクトリとファイルを作成し、設定を行います。 |
| `start.sh` | JpyNetworkとLariNetworkの両方のノードとトークンブリッジを起動し、P2P接続を確立し、マイニングを開始します。 |
| `status.sh` | 両方のネットワークの現在の状態、ブロック高、P2P接続、トークンブリッジの状態を表示します。 |
| `stop.sh` | すべてのサービスを安全に停止します。 |
| `create_desktop_shortcut.sh` | デスクトップに便利なショートカットを作成します。 |
