# セットアップガイド

このセクションでは、BSVネットワーク（JpyNetworkとLariNetwork）をセットアップするための手順を説明します。

## 内容

- [前提条件](prerequisites.md) - セットアップに必要なソフトウェアと環境
- [インストール手順](installation.md) - ソフトウェアのインストール方法
- [初期設定](configuration.md) - ネットワークの初期設定方法

## クイックスタート

すぐに始めたい場合は、以下のコマンドを実行してください：

```bash
git clone https://github.com/space0org/Multi-Bsv-Network.git
cd Multi-Bsv-Network/one-click-setup
./setup.sh
./start.sh
```

これにより、両方のネットワークとトークンブリッジが自動的に起動します。
